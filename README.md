# 🎮 Los Super Ninis — Official Website

Welcome to the official website of **Los Super Ninis**, a chaotic indie game studio from Madrid.  
This project blends **retro-comic visuals**, **gritty textures**, **dotted gradients**, and **SvelteKit magic** to create a fast, multilingual, progressively-enhanced experience.

## 🛠 Tech Stack
- **SvelteKit 2 / Svelte 5**
- **i18n** for translations
- **Cloudflare Pages + Workers** deployment
- **Static + dynamic hybrid rendering**
- **SVG-based shapes & masked textures**

---

## 🚀 Development

Install dependencies:

```bash
npm install
````

Run the development server:

```bash
npm run dev
```

Generate the Cloudflare build:

```bash
npm run build
```

Preview locally:

```bash
npm run preview
```

---

## ☁️ Deployment (Cloudflare Pages)

The project uses:

* **Cloudflare Pages** for static hosting
* **Cloudflare Workers / Edge Functions** for SSR where needed

Build settings:

```
Build command: npm run build
Output directory: .svelte-kit/cloudflare
```

## 🤝 Contributing

We welcome **feedback, bug reports, ideas, and suggestions** to help improve performance, accessibility, and stability.
However, this website is an official Los Super Ninis production, and we prefer to keep full creative and structural control.

**Pull requests are not accepted**, except for:

* Minor grammar or spelling fixes
* Translation improvements
* Small documentation corrections

For everything else, we’d love to hear from you — just not merge it directly!
